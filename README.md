# Stylo

A clean, mobile-first, zero-build fashion recommendation web app.

## Features
- Photo preview handled locally in the browser
- Occasion, weather, fit and style controls
- Deterministic outfit recommendations
- No API key, backend, account or build step
- GitHub Pages ready

## Run
Open `index.html` locally or publish the repository with GitHub Pages.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Expected URL:
https://devsoni1789-cell.github.io/Stylo/

## Privacy
The app does not upload the selected photo. It is not a biometric recognition or virtual try-on system.
